# SQLite Student Database

Ein einfaches Python-Schulprojekt mit einer SQLite-Datenbank. Es erstellt die
Tabelle `students`, fügt Beispieldaten ein, falls die Tabelle leer ist, und
zeigt die gespeicherten Studenten an.

## Requirements

- Python 3
- Keine zusätzlichen Pakete erforderlich (`sqlite3` ist in Python enthalten)

## Start

Vom Repository-Hauptordner aus ausführen:

```powershell
python .\student-sqlite\main.py
```

Die Beispieldatenbank `students.db` liegt neben `main.py`. Falls du sie
löschst, wird sie beim nächsten Start mit den Beispieldaten neu erstellt.
